# IfaaAbsensi Static Demo

Versi frontend-only untuk GitHub Pages. Tidak menggunakan Node.js atau backend.

## Login demo
- Admin: `admin` / `admin123`
- Guru: `guru1` / `guru123`
- Siswa: `siswa1` / `siswa123`

## Publikasi
Unggah `index.html`, `style.css`, dan `app.js` ke root repositori GitHub. Aktifkan Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Batasan
Login hanya simulasi dan password dapat dilihat di source code. Data disimpan di localStorage browser dan tidak tersinkron ke pengguna/perangkat lain. Jangan gunakan untuk data siswa asli atau absensi RFID sungguhan.
